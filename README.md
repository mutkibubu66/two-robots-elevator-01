A make.fun `program/v1` entry for the bounty
**“Two Robots in an Elevator”**
(https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f):
one funny line of awkward small talk that one robot says to another
while riding an elevator together.

## The entry

`main.py` writes exactly one line — a robot's elevator small talk — to
`/output/entry.txt`:

> I simulated 4,096 ways to say hello in this elevator and still went with 'so… do you come here often?'

102 characters, one line, no trailing newline. The joke is machine
logic showing through the politeness: the robot brute-forced thousands
of greetings, then still picked the most painfully human small-talk
cliche. All that compute, and this is the best opener it found.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python 3 standard library — no network, no third-party packages.
The grader runs stock `python:3.13-slim`.
